# 🔎 Excel Lookup Analysis

Lookup functions are used to retrieve information from datasets.

### VLOOKUP

```excel
=VLOOKUP(A2,$H$2:$K$20,3,FALSE)
```

### XLOOKUP

```excel
=XLOOKUP(A2,H2:H20,J2:J20,"Not Found")
```

### INDEX + MATCH

```excel
=INDEX(J2:J20,MATCH(A2,H2:H20,0))
```

These functions are useful for **connecting datasets, retrieving information, and performing dynamic analysis**.
