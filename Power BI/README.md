## 🧮 DAX

DAX is used to create calculated measures and analytical expressions.

### DAX Concepts Practiced

* Measures
* Calculated Columns
* Calculated Tables
* SUM
* SUMX
* COUNT
* COUNTROWS
* DISTINCTCOUNT
* AVERAGE
* MIN
* MAX
* CALCULATE
* FILTER
* ALL
* ALLEXCEPT
* DIVIDE
* IF
* SWITCH
* DATE functions
* Time Intelligence

### Example

```DAX
Total Sales =
SUM(Sales[SalesAmount])
```

```DAX
Total Orders =
COUNTROWS(Sales)
```

```DAX
Average Sales =
AVERAGE(Sales[SalesAmount])
```

```DAX
Sales Growth % =
DIVIDE(
    [Current Sales] - [Previous Sales],
    [Previous Sales],
    0
)
```
