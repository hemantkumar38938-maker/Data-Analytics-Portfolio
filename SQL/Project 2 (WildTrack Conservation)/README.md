## 📌 Project Overview

**WildTrack Conservation Alliance** is a SQL-based **Wildlife Conservation Database and Analytics Project** designed to demonstrate relational database management, SQL analysis, data integrity, performance optimization, and security concepts.

The project contains **10,000 records across 4 relational tables** and explores real-world conservation scenarios through SQL-based analysis.

**Project Type:** Relational Database + Analytics
**Technology:** MySQL / SQL
**Domain:** Wildlife Conservation
**Scope:** 10,000 Records • 4 Tables • 75 Business Scenarios
**Prepared by:** R Hemant Kumar Patra

The primary objectives of this project are to:

## 🗃️ Database Overview

The project is built as a relational database containing **4 interconnected tables** with approximately **10,000 records**.

```text
                WildTrack Database
                       │
        ┌──────────────┼──────────────┐
        │              │              │
     Table 1        Table 2        Table 3
        │              │              │
        └──────────────┼──────────────┘
                       │
                    Table 4
```

The relational structure allows different conservation entities and activities to be connected and analyzed through SQL queries.
